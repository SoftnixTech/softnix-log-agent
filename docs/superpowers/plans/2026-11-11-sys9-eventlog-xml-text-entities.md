# SYS-9 Eventlog XML Text Entities Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking. Execute the tasks in order. Every commit-producing task ends with the full gate.

**Goal:** Every `<Data>` element (and every System text field the parser reads) produces one value with XML entity and character references resolved, instead of being cut at the first `&…;`. The parser also moves to a module whose tests run on every platform.

**Architecture:** `ParsedEvent` and `parse_event_xml` move from the Windows-only `src/inputs/eventlog.rs` to `src/inputs/eventlog_xml.rs` (`#[cfg(any(windows, test))]`). The parser then builds each element's text across `Event::Text` and `Event::GeneralRef`, and assigns it once, on `End`.

**Tech Stack:** Rust 2021, `quick-xml` 0.41 (`BytesRef::resolve_char_ref`, `escape::resolve_predefined_entity`), `quick-xml` added as a dev-dependency.

**Spec:** `docs/superpowers/specs/2026-11-11-sys9-eventlog-xml-text-entities.md`
**Follow-up plan (same branch, runs after this one):** `docs/superpowers/plans/2026-11-11-sys8-eventlog-xml-attribute-unescape.md`

  Write `/tmp/sys89/stages.py` with the content below. This is the dry-run-verified version.

  ```python
  """Build the per-commit states of src/inputs/eventlog_xml.rs for the
  SYS-9 / SYS-8 plans from (a) the parser as it was at cf5bc5a and (b) the
  final trial file. Usage:
    python3 -I stages.py c2       <final> <out>   # refactor: verbatim move
    python3 -I stages.py c3-red   <final> <out>   # C2 parser + SYS-9 tests
    python3 -I stages.py c3-green <final> <out>   # final minus SYS-8
    python3 -I stages.py c6-red   <final> <out>   # final with only the SYS-8 attr change reverted
  Run from the repo root (uses `git show cf5bc5a:...`)."""
  import subprocess, sys

  ORIG_ATTR = '''    let attr = |e: &quick_xml::events::BytesStart, name: &[u8]| -> Option<String> {
          e.attributes().flatten().find_map(|a| {
              if a.key.as_ref() == name {
                  Some(String::from_utf8_lossy(&a.value).into_owned())
              } else {
                  None
              }
          })
      };
  '''
  HEADER = '''//! Parser for the XML that `EvtRender` produces for a Windows Event Log
  //! record (`<Event><System>…</System><EventData>…</EventData></Event>`).
  //!
  //! Split out of `eventlog.rs` because it is pure string processing with no
  //! Windows API: compiled on Windows (used by `eventlog::build_event`) and in
  //! test builds on every platform, so its tests run locally and in every CI
  //! job, not only `test-windows`. Release builds on other platforms do not
  //! include it (see `src/inputs/mod.rs`).

  /// Fields pulled out of one event's XML.
  ///
  /// On non-Windows test builds only the tests read these fields, so any field
  /// the tests don't happen to read would trip `dead_code` under `-D warnings`.
  #[derive(Default)]
  #[cfg_attr(not(windows), allow(dead_code))]
  pub(super) struct ParsedEvent {
  '''

  def cut(s, start, end):
      a = s.index(start); b = s.index(end, a)
      return s[a:b]

  def c2():
      head = subprocess.run(['git', 'show', 'cf5bc5a:src/inputs/eventlog.rs'],
                            capture_output=True, text=True, check=True).stdout
      parser = cut(head, '#[derive(Default)]\nstruct ParsedEvent {', '#[cfg(test)]\nmod tests {').rstrip('\n') + '\n'
      struct_end = parser.index('}\n') + 2
      struct, rest = parser[:struct_end], parser[struct_end:]
      body = struct.split('struct ParsedEvent {\n', 1)[1]
      body = ''.join('    pub(super) ' + l[4:] + '\n' if l.startswith('    ') else l + '\n'
                     for l in body.rstrip('\n').split('\n'))
      assert rest.count('\nfn parse_event_xml(') == 1
      rest = rest.replace('\nfn parse_event_xml(', '\npub(super) fn parse_event_xml(')
      tests = cut(head, '    const SAMPLE: &str = ', '    #[test]\n    fn level_maps_to_syslog_severity()').rstrip('\n')
      assert tests.count('#[test]') == 1 and 'fn parses_system_and_eventdata' in tests
      return HEADER + body + rest + '\n#[cfg(test)]\nmod tests {\n    use super::*;\n\n' + tests + '\n}\n'

  def split_tests(src):
      i = src.index('#[cfg(test)]\nmod tests {')
      return src[:i], src[i:]

  def drop_sys8_tests(tests):
      a = tests.index('    // --- SYS-8: attribute values must be unescaped ---\n')
      b = tests.index('    // --- Guards:', a)
      return tests[:a] + tests[b:]

  def revert_attr(s):
      a = s.index('    // Attribute values with references resolved (SYS-8).')
      b = s.index('    };\n', a) + len('    };\n')
      s = s[:a] + ORIG_ATTR + s[b:]
      assert s.count('    use quick_xml::XmlVersion;\n') == 1
      return s.replace('    use quick_xml::XmlVersion;\n', '')

  def c6_red(final):
      return revert_attr(final)

  def c3_green(final):
      code, tests = split_tests(revert_attr(final))
      return code + drop_sys8_tests(tests)

  def c3_red(final):
      code, _ = split_tests(c2())
      _, tests = split_tests(final)
      return code + drop_sys8_tests(tests)

  if __name__ == '__main__':
      stage, final_path, out = sys.argv[1:]
      final = open(final_path).read()
      out_s = {'c2': lambda: c2(), 'c3-red': lambda: c3_red(final), 'c3-green': lambda: c3_green(final), 'c6-red': lambda: c6_red(final)}[stage]()
      open(out, 'w').write(out_s)
      print(f'{stage}: wrote {out} ({out_s.count(chr(10))} lines)')
  ```

  Below, `stages` and `FINAL` mean `stages() { python3 -I /tmp/sys89/stages.py "$@"; }` and `FINAL=/tmp/sys89/final_eventlog_xml.rs`. Use a function, not `S="python3 …"; $S …`: zsh (the default macOS shell) does not word-split `$S`, so it looks for a command literally named "python3 -I …" and nothing runs. This happened during execution on 2026-11-11.

## Risks

- **`eventlog.rs` cannot be compiled locally.** The change there is removals plus one import, checked by `cargo fmt` and by T1 step 2's diff. A Windows-only mistake would surface only in CI's `test-windows` job (V6).
- **The generated states depend on exact anchor strings** in `stages.py`. Every function `assert`s its anchors, so a mismatch stops with a traceback instead of writing a wrong file. Each state is also checked by diff or test count before it is committed.
- **`/tmp/sys89` is temporary.** Run T0–T2 in one sitting. If it disappears before C2, redo T0 steps 4–5: the working tree still holds the final file. If it disappears after C3, nothing in this plan needs it any more, and the SYS-8 plan has its code written out verbatim, so it can be applied by hand.
